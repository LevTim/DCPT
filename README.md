Варіант 9: Використання Вейвлет-перетворень

Реалізуйте розбиття часових рядів споживання енергії на частотні складові за
допомогою Wavelet Transform. Порівняйте з аналізом Фур'є. Візуалізуйте частотні
компоненти для порівняння з результатами Фур'є.

Навіщо це можна використовувати?

Прогнозування навантаження (Load Forecasting): Виділення чітких добових та тижневих циклів дозволяє енергетичним компаніям планувати генерацію (наприклад, знати, коли вмикати додаткові потужності).

Діагностика аномалій та аварій: Вейвлети дозволяють миттєво фіксувати короткочасні стрибки або просідання напруги, які "невидимі" для класичного аналізу Фур'є через їхню неперіодичність.

Очищення даних від "шуму": Видалення випадкових коливань (високочастотних вейвлет-коефіцієнтів) для отримання чистого тренду споживання, що важливо для стратегічного планування на місяці вперед.

Логіка роботи:
Генерація синтетичного сигналу: Імітація реального споживання шляхом накладання синусоїд (день/тиждень) та випадкового гауссового шуму.

Швидке перетворення Фур'є (FFT): Переведення сигналу з часової області у частотну для ідентифікації "сильних" періодів (наприклад, пік на 24 годинах).

Дискретна декомпозиція (DWT): Розбиття сигналу на рівні (L0–L4) за допомогою вейвлета Добеші (db4). Це дозволяє відокремити загальний тренд (апроксимація) від дрібних деталей (деталізація).

Безперервне перетворення (CWT): Створення скалограми (time-frequency map) для спостереження за тим, як частотні характеристики сигналу змінюються в кожну конкретну хвилину.

Реконструкція сигналу: Зворотне вейвлет-перетворення для перевірки цілісності даних та підтвердження відсутності втрат при аналізі.

Головні "фішки" 

Time-Frequency Resolution (CWT): Використання вейвлета Морле ('morl') дає змогу бачити не просто частоти, а їхню тривалість у часі. Це головна перевага над Фур'є.

Багаторівнева декомпозиція (wavedec): Скрипт автоматично ділить енергоспоживання на шари. Кожен шар відповідає за свій масштаб: від хвилинних коливань до багатоденних трендів.

Векторизовані обчислення NumPy: Розрахунок FFT та CWT виконується на рівні оптимізованих C-бібліотек, що дозволяє обробляти великі масиви даних сенсорів (Smart Meters) майже миттєво.

Математична валідація (waverec): Порівняння відновленого сигналу з оригіналом (графік 4) гарантує 100% точність математичної моделі, що критично для фінансових розрахунків в енергетиці.

Інтуїтивна візуалізація: Використання теплової карти (imshow з картою jet) для CWT дозволяє менеджеру без математичної освіти побачити "ритм" підприємства візуально.
