Завдання 9 

Обробка категоріальних даних: Реалізувати перетворення категоріальних змінних в числові за допомогою методів, таких як one-hot encoding або label encoding.

Як працює код

Label Encoding
Цей метод працює як звичайний список у блокноті. Він дивиться на всі унікальні назви кольорів, сортує їх за алфавітом і видає кожному «порядковий номер».

Синій став 0, Зелений — 1, Червоний — 2.

У результаті замість назв ми маємо один стовпець із цифрами.

One-Hot Encoding
Тут підхід інший: «один активний, інші — ні». Для кожного кольору створюється окрема колонка.

Якщо в рядку був «Зелений», то в колонці Колір_Зелений стоїть 1, а в інших — 0.

Це створює розріджену матрицю (багато нулів і одиниць).

Фішки кожного методу

Фішки Label Encoding:

Компактність: Це ідеально для величезних баз даних. Якщо у вас 1000 різних категорій (наприклад, назви міст), Label Encoding залишить лише один стовпець, а One-Hot створить тисячу нових, що може «підвісити» комп'ютер.

Швидкість: Дерева рішень (Random Forest, XGBoost) обожнюють цей метод. Вони легко розділяють дані за числами: «якщо код менше 2 — це одна група, якщо більше — інша».

Фішки One-Hot Encoding:

Рівноправність: Це головна фішка. Модель не буде думати, що «Червоний (2)» кращий або важливіший за «Синій (0)». Всі кольори стають незалежними координатами у просторі.

Точність для лінійних моделей: Для нейромереж або логістичної регресії це стандарт. Без цього модель почне рахувати середнє арифметичне між кольорами, що не має сенсу.

Де це знадобиться в житті?

Label Encoding:

Рівень лояльності клієнта: Bronze (0), Silver (1), Gold (2), Platinum (3). Тут цифри мають сенс, бо Platinum дійсно «більше» за Bronze.

Розміри товарів: XS, S, M, L, XL.

Стадії виробництва: Замовлення прийнято -> Збирається -> Відправлено -> Доставлено.

One-Hot Encoding:

Типи платежів: Карта, Готівка, Apple Pay, Google Pay. Жоден метод не є «першим» або «другим» за значенням.

Жанри фільмів: Комедія, Драма, Жахи. Фільм не може бути «більшим» за жанром, ніж інший.

Країни та міста: Коли ви аналізуєте ринок, де кожна локація — це окрема незалежна змінна.
