Агент оптимізації навантаження

Аналіз піків навантаження і рекомендації для їх зменшення.

Основна мета проєкту — автоматизація процесу планування навантаження. Агент аналізує динаміку споживання, виявляє аномальні піки, що створюють загрозу стабільності мережі або призводять до фінансових втрат, і генерує стратегію перенесення енерговитрат на більш вигідні періоди.
Проєкт охоплює повний життєвий цикл розробки агента:  

 -Генерацію та обробку синтетичних даних.  
 
 -Побудову прогнозної моделі на основі машинного навчання.  
 
 -Розробку логіки прийняття рішень (policy) за допомогою алгоритмів оптимізації.  
 
 -Оцінку якості роботи через бізнес-метрики (економія коштів).

Ключові поняття

Predictive Analytics (Прогнозна аналітика): Використання історичних часових рядів для передбачення майбутньої поведінки системи.

Random Forest Regressor: Ансамблевий метод машинного навчання, який я обрав за його стійкість до викидів у даних та здатність працювати з нелінійними залежностями (наприклад, вплив температури на споживання).

SLSQP (Sequential Least Squares Programming): Високотехнологічний алгоритм оптимізації, який дозволяє мінімізувати цільову функцію (витрати) при суворих обмеженнях (збереження загального обсягу спожитої енергії).

Demand Response (Керування попитом): Технологія, що дозволяє споживачам активно реагувати на цінові сигнали ринку, зменшуючи навантаження в найдорожчі години.

Сфери застосування

Ця розробка має широкий спектр практичного впровадження:

Промислові підприємства: Автоматичне перенесення енергомістких процесів (наприклад, плавка або запуск потужних верстатів) на нічні зміни.

Розумні будинки (Smart Home): Інтеграція з побутовою технікою (пральні, посудомийні машини), щоб вони запускалися автоматично в часи найнижчого тарифу.

Зарядні станції для електромобілів (EV Charging): Оптимізація графіків зарядки великого парку авто, щоб не перевантажувати міську мережу ввечері.  

Мікромережі (Microgrids) та ВДЕ: Балансування споживання при використанні сонячних панелей та акумуляторів (BESS).  

Сценарії тестування

Для демонстрації роботи агента я підготував 3 тестові сценарії:  

Тест №1: Стандартний день. Агент успішно переносить навантаження з вечірнього піка (19:00) на нічний мінімум (03:00), демонструючи економію близько 5-7%.

Тест №3: Рівний тариф. Агент демонструє свою "інтелектуальність" — він бачить, що ціна енергії однакова весь день, і повідомляє, що перенесення навантаження недоцільне, оскільки воно не принесе економії.
