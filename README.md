Автоматизований скрипт на Python для перевірки логіки сортування товарів на сайтах електронної комерції (на прикладі інтернет-магазину Foxtrot). 

Скрипт збирає ціни товарів на сторінці, застосовує фільтр сортування ("Від дешевих до дорогих"), чекає на динамічне оновлення контенту та порівнює середню ціну до та після сортування.

## Навіщо це можна використовувати?

1. **QA Automation (Тестування):** Автоматична перевірка того, чи коректно працюють фільтри та сортування на сайті після оновлень (регресійне тестування).
2. **Парсинг та Аналітика (Web Scraping):** Збір актуальних цін конкурентів для моніторингу ринку.
3. **Моніторинг аномалій:** Швидкий пошук помилок у ціноутворенні (наприклад, якщо після сортування "від дешевих" середня ціна раптом зростає).

## 🛠 Як це реалізовано (Стек технологій)

- **Мова:** Python 3
- **Бібліотеки:** `selenium`, `webdriver-manager`
- **Логіка роботи:**
  1. Запуск браузера (через автоматично завантажений ChromeDriver).
  2. Парсинг елементів з цінами за допомогою CSS-селекторів.
  3. Очищення тексту від валют та пробілів за допомогою регулярних виразів (`re`).
  4. Імітація дій користувача (відкриття dropdown-меню, вибір опції).
  5. Очікування оновлення DOM-дерева (AJAX).
  6. Повторний збір даних та математичне порівняння результатів.

##  Головні "фішки" (Особливості коду)

*  **Headless Mode + User-Agent Spoofing:** Скрипт працює у фоновому "безголовому" режимі (`--headless=new`), що економить ресурси. Щоб уникнути блокування антибот-системами, використовується підміна `User-Agent` та фіксована роздільна здатність вікна (`--window-size=1920,1080`).
*  **Smart Waits (Розумні очікування):** Замість жорстких та нестабільних `time.sleep()`, код використовує `WebDriverWait` (Explicit Waits). 
*  **Обробка динамічного контенту (AJAX):** Найскладніший етап — очікування оновлення товарів після кліку. Реалізовано через перевірку `EC.staleness_of()`, що гарантує збір саме *нових* цін, а не залишків старих даних (запобігає `StaleElementReferenceException`).
*  **Регулярні вирази (Regex):** Використання патерну `\D` для швидкого та надійного видалення всіх нечислових символів (пробілів, літер, знаків валют) з рядків типу "25 999 ₴" для їх конвертації у тип `float`.
*  **JavaScript Clicks:** Кліки по елементах сортування виконуються через `driver.execute_script()`, що дозволяє обійти проблему перекриття кнопок іншими елементами (наприклад, невидимими панелями або банерами).
*  **Обробка попапів:** Додано блок `try-except` для безпечного закриття спливаючих вікон (cookie, вибір міста), які можуть блокувати взаємодію зі сторінкою.
